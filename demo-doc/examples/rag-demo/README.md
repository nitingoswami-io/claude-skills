# Reference example: rag-demo

The approved RAG Demo design document, in every output format:

| File | What it is |
|---|---|
| `DESIGN.md` | Markdown source of truth (what goes in the demo repo's `docs/`) |
| `figures/fig-01…09-*.svg` | The nine hand-drawn figures; one of each diagram type |
| `design.html` | Standalone spec-sheet page, built from `assets/template.html` with the figures inlined by `scripts/figures.py inline` |
| `demo.mdx` | Website post (`content/demos/rag-demo.mdx`) |

The demo lives at https://github.com/nitingoswami-io/rag-demo. These files match its `docs/` folder and its `CONTRIBUTING.md`, which was generated from `assets/CONTRIBUTING.template.md`.
